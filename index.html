PRISMA

Tecnología que acerca personas.

PRISMA es un proyecto tecnológico enfocado en facilitar la interacción entre personas usuarias de LESCO y personas oyentes mediante herramientas digitales, programación y recursos visuales.

PROCESO

Cómo funciona.

01

Entrada

El usuario proporciona texto o información relacionada con una seña.

02

Procesamiento

PRISMA procesa la información mediante la lógica desarrollada para el prototipo.

03

Representación

El sistema presenta el resultado utilizando texto o recursos visuales de LESCO.
